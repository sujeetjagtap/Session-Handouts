# AI Writing Training — Demonstration Kit
### "From Prompt to Publication: A Hands-on AI Writing Workflow"
Series: *AI-Assisted Scientific Writing and Journal Publication for Researchers* · 2-hour live session · built 2026-10-04

## What this kit is

The complete companion to the 39-slide training deck (`From_Prompt_to_Publication_Training.pptx`).
It contains every file you need to **deliver, participate in, or re-deliver** the session:
the minute-by-minute run sheet, every live-demo prompt ready to copy, hands-on exercise
materials, and the integrity templates (disclosure, verification, publisher policies).

## Three ways to use it

1. **As the trainer** — read `00_RUN_SHEET.md` once, keep `demo_cue_script.md` open on a
   second screen, and copy prompts from the cookbook live. Total prep time: ~45 minutes.
2. **As a participant** — you only need `2_participant_pack/` during the session, and
   `3_integrity_pack/` afterwards when you write.
3. **As a re-deliverer** — the run sheet maps every segment to slide numbers, demos, and
   files, so a colleague can deliver the session from this kit alone.

## Ground rules baked into every file

- Every prompt works in **any mainstream chatbot** (the workflow is the tool, not the vendor).
- Nothing here helps evade AI detection or disclosure — the session's position is that
  specificity, verification, and honest disclosure are what make text publishable.
- Facts and policy quotes carry source names and a snapshot date; always confirm the
  journal's current author guide before relying on them.
