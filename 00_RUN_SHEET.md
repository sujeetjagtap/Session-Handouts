## Contingency rules

- **Model slow/unresponsive** → every demo has a pre-captured fallback in `demo_cue_script.md` §"If it fails". Never stall more than 60 seconds — switch to the fallback and keep talking.
- **Running 5+ min late** → cut slide 21's captions column and slide 35's reviewer-response card; never cut D8 (it is the emotional peak and the compliance payoff).
- **Running early** → extend the Your-Turn debrief (slide 22) and the Q&A; do not add new content.
- **No internet at the venue** → run the session fully from `weak_vs_strong_examples.md` + `demo_cue_script.md` fallbacks; all demo outcomes are pre-recorded there as text.
